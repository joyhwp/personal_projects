# Credit Card Customer Segmentation

## Overview
Segmented credit card customers through clustering to understand usage patterns, deriving insights applicable to targeted marketing strategies and business decision-making.

## Approach

**1. Exploratory Data Analysis & Preprocessing**
- Conducted thorough EDA and preprocessing (including scaling) to improve data quality before clustering

**2. Model Implementation**
- Implemented multiple clustering algorithms with defined parameter settings: K-Means, DBSCAN, and Gaussian Mixture Model (GMM)

**3. Model Evaluation**
- Evaluated each model using silhouette scores and cluster visualizations, with documented rationale for each evaluation

**4. Model Selection**
- Selected the optimal clustering model based on evaluation results, with clear justification for the choice

**5. Insight Generation**
- Interpreted the characteristics of each resulting cluster
- Derived marketing strategies and business insights for each customer segment, incorporating relevant business/strategy frameworks

## Tech Stack
`Python` `scikit-learn` `KMeans` `DBSCAN` `GMM`
