# ⭐ Featured Project

## 01. IMDB Movie Review Sentiment Analysis
Built an NLP model to predict positive/negative sentiment from IMDB movie review text, and derived business insights applicable to the film industry based on the results.
`Python` `NLP` `scikit-learn`

## 02. Heart Disease Prediction
Built classification models to predict the likelihood of heart disease based on patient clinical data, and compared the performance of four models (Logistic Regression, Decision Tree, Random Forest, SVM).
`Python` `scikit-learn` `Classification`

## 03. Body Fat Percentage Prediction
Developed a regression model to predict body fat percentage from various body measurements and identify the key factors influencing it.
`Python` `scikit-learn` `Regression`

## 04. Credit Card Customer Segmentation
Segmented credit card customers through clustering to understand usage patterns, deriving insights applicable to targeted marketing strategies.
`Python` `KMeans` `DBSCAN` `GMM`

## 05. Melon Music Chart Crawling
Built a web crawling pipeline using Selenium to automatically collect data from Melon's music chart.
`Python` `Selenium` `Web Crawling`

## 06. Adidas Sales Dashboard
Created an interactive Tableau dashboard to explore Adidas sales trends by region, product, and time period.
`Tableau`
